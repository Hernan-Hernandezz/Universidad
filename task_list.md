# Lista de Tareas y Plan de Ejecución del Proyecto

Este documento representa el backlog estructurado de desarrollo del diseño del sistema. Las tareas deben ejecutarse de manera secuencial siguiendo el proceso profesional establecido.

---

## FASE 1: Definición de Identidad Visual y UI Specs

- [x] **Tarea 1.1:** Selección de la tipografía principal del sistema (**Roboto**) y tipografía técnica (**Roboto Mono**).
- [x] **Tarea 1.2:** Definición de la paleta de colores monocromática (`#004959`, `#368FA2`, `#ACF2FF`) y el color de alerta (`#AE443A`).
- [x] **Tarea 1.3:** Selección de la biblioteca homogénea de iconografía (**Phosphor Icons**).
- [x] **Tarea 1.4:** Elección de las herramientas de software de diseño y prototipado.

---

## FASE 2: Comprensión del Problema y Organización de Información (FASE ACTUAL)

- [x] **Tarea 2.1:** Realizar el análisis de las 8 frustraciones principales del estudiante recopiladas en el contexto del problema (pérdida de horarios, olvido de tareas, desubicación de salones, problemas emocionales, falta de contacto con docentes, pérdida de eventos y ausencia de app centralizada).
- [ ] **Tarea 2.2:** Diseñar la arquitectura de información detallada para el **Módulo de Autenticación** (Login, recuperar contraseña, verificación de correo, carga y error).
- [ ] **Tarea 2.3:** Diseñar la arquitectura de información y jerarquía de datos para las tarjetas del **Dashboard Principal** (Resumen, próximas clases, tareas, alertas, estado emocional y accesos rápidos).
- [ ] **Tarea 2.4:** Estructurar el flujo de datos y navegación para la **Gestión de Horarios** (Vista semanal, conflictos y visualización de salones).
- [ ] **Tarea 2.5:** Estructurar la lógica visual de la **Gestión Académica**, prestando especial atención a la distribución de la herramienta interactiva del _Simulador de Notas_.
- [ ] **Tarea 2.6:** Diseñar la experiencia y flujos del módulo de **Bienestar Estudiantil** (Cuestionario emocional, agenda de citas y confidencialidad).
- [ ] **Tarea 2.7:** Definir la disposición de los elementos del módulo de **Comunicación** (Chat de docentes, tablón de anuncios institucionales y centro de notificaciones).

---

## FASE 3: Construcción de Wireframes (Baja Fidelidad)

- [ ] **Tarea 3.1:** Crear bocetos estructurales rápidos de las pantallas de Autenticación.
- [ ] **Tarea 3.2:** Diseñar el esqueleto del Dashboard Principal, validando que no exista saturación visual de los componentes.
- [ ] **Tarea 3.3:** Crear el wireframe estructural de la vista de calendario semanal para la Gestión de Horarios.
- [ ] **Tarea 3.4:** Diseñar el wireframe de Gestión Académica, ubicando claramente el área de materias y la sección interactiva del simulador.
- [ ] **Tarea 3.5:** Crear los wireframes de Bienestar Estudiantil y Comunicación (Estructura de chat y formularios de test).
- [ ] **Tarea 3.6:** Validar la navegación estructural de los wireframes respondiendo al flujo de entrada, cambio de pantalla y retorno sin añadir color.

---

## FASE 4: Construcción de Mockups (Alta Fidelidad)

- [ ] **Tarea 4.1:** Aplicar la tipografía Roboto y Roboto Mono a todos los textos del diseño según su jerarquía.
- [ ] **Tarea 4.2:** Implementar la paleta de colores monocromática, asegurando un contraste limpio entre fondos y textos.
- [ ] **Tarea 4.3:** Aplicar el color de alerta `#AE443A` en las pantallas de error de acceso, alertas del dashboard y elementos críticos vencidos.
- [ ] **Tarea 4.4:** Integrar los iconos de Phosphor Icons de forma consistente en menús, botones y tarjetas informativas.
- [ ] **Tarea 4.5:** Diseñar los botones de acción principal, secundaria y estados deshabilitados siguiendo el principio de consistencia.
- [ ] **Tarea 4.6:** Adaptar todos los mockups visuales en versiones específicas para entornos web (Escritorio) y dispositivos móviles (Responsive).

---

## FASE 5: Creación del Prototipo e Interacción

- [ ] **Tarea 5.1:** Conectar las pantallas del flujo de Autenticación con el Dashboard Principal tras simular un inicio de sesión exitoso.
- [ ] **Tarea 5.2:** Configurar las transiciones de los clics y menús de navegación rápida para saltar ágilmente entre los 6 módulos.
- [ ] **Tarea 5.3:** Simular la interacción del ingreso de notas dentro del módulo interactivo del simulador de rendimiento académico.
- [ ] **Tarea 5.4:** Configurar los flujos de navegación inversa (botones de regresar) y menús colapsables para asegurar una experiencia intuitiva.
- [ ] **Tarea 5.5:** Realizar pruebas de usabilidad del prototipo interactivo final para asegurar el cumplimiento total de los objetivos de diseño.
